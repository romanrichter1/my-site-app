# Háčky (úvodní slidy) pro carousely

Styl podle Romanem dodaných příkladů (@rishi): jedna plná barva, obří tučné verzálky, ručně kreslený křížek, malá věta v závorce.
V barvách Nexiva: limetková / černá, Inter Display Black + Fraunces italic, dole jen logo (žádné jméno).

| Soubor | Agent | Vzorec |
|---|---|---|
| 01 | poptávky | „Přestaňte [běžná praxe]“ + ✕ |
| 02 | poptávky | „[Věc], kterou skoro nevidím“ |
| 03 | recenze | „Přestaňte prosit o recenze“ + ✕ |
| 04 | recenze | „Trik, který skoro nikdo nepoužívá“ |
| 05 | kalkulace | „Přestaňte počítat nabídky ručně“ + ✕ |
| 06 | kalkulace | „Tohle ve stavebnictví skoro nikdo nedělá“ |

Celé carousely s háčkem „Přestaňte…“: `*-agent-v3/`. Zdroj: `social/tools/carousel-v2/build.py` (HOOKS).
